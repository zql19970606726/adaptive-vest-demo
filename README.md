# 适老化安全马甲微信扫码功能演示

这是一个可直接用微信扫描的网页演示，内容对应视频中的三个主要操作：

- 页面内置 58 秒作品实录（540p 流畅版，约 4 MB），点击即可在微信内播放；
- 手机端显示佩戴者位置与最近轨迹；
- 红、黄、绿三色按键分别模拟紧急求助、外出和到家；
- 右侧同步显示家属微信服务通知和事件时间线。

## 现场演示

1. 在 Windows“设置 → 网络和 Internet → 移动热点”中开启热点。
2. 热点名称设为 `SCV-VEST`，密码设为 `20261111`。
3. 确认热点适配器地址为 `192.168.137.1`，可运行 `ipconfig` 查看。
4. 双击 `启动微信功能演示.bat`，保持命令窗口运行。
5. 手机连接 `SCV-VEST`，用微信扫描 `微信扫码功能演示二维码_贴纸.png`。

微信扫描后会打开 `http://192.168.137.1:8080/` 交互演示页。电脑、热点和命令窗口都必须保持运行。
